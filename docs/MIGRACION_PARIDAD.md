# Matriz de paridad: Sistema PHP → Laravel

Esta matriz se basa en los manuales y suites vigentes del PHP de origen y en rutas, controladores, servicios, modelos, migraciones y pruebas del Laravel actual. “Migrado” requiere comportamiento equivalente y pruebas pertinentes; el mero hecho de que exista una página o clase no basta. Los resultados históricos del repo fuente son evidencia del origen, no pruebas de Laravel.
