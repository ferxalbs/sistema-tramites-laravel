# Modelos institucionales pendientes

La **constancia de modalidad de examen de titulación** tiene un ejemplo aportado por el usuario y el PDF final ya incorpora el texto completo del borrador aprobado. Falta verificar la presentación visual contra un archivo fuente oficial.

Para **justificación de tardanza** y **constancia de prácticas**, aún no se han recibido los modelos institucionales. No se debe inventar texto oficial, firmas, destinatarios obligatorios ni criterios de aprobación. El sistema permite registrar el FUT y preparar un borrador con un **modelo referencial propio para cada tipo**. La vista previa PDF muestra «MODELO REFERENCIAL — NO OFICIAL» y la emisión del PDF oficial de estos dos tipos continúa bloqueada.

## Referencias públicas examinadas el 5 de octubre de 2026

- [Manual de procesos académicos 2025 del IESTP «Manuel Seoane Corrales»](https://seoane.edu.pe/wp-content/uploads/2025/12/MPA-2025.pdf): describe la presentación del FUT y menciona constancias de prácticas y actas de evaluación, pero **no contiene las plantillas finales de los dos trámites**.
- [Modelo de constancia de prácticas de la PUCP, anexo 1](https://facultad-derecho.pucp.edu.pe/wp-content/uploads/2025/11/guia-para-practicantes-2023_compressed.pdf): referencia externa para identificar periodo y centro de prácticas. Sus requisitos y su texto no se atribuyen al IESTP.
- [FUT del IESPP José Crisam](https://www.josecrisam.edu.pe/documentos/Formato_FUT_JoseCrisam.pdf): incluye la justificación de tardanza entre las solicitudes y muestra campos de fundamento y anexos. Es una referencia externa de captura, no el modelo de respuesta del IESTP.

Estas referencias ayudan a probar la captura de datos y la vista previa. Ningún PDF de otra institución se distribuye como modelo del IESTP. Los modelos referenciales están en estado `borrador`, solo pueden vincularse al tipo de solicitud correspondiente y no consumen numeración oficial.

La firma pública [Signature example.png](https://commons.wikimedia.org/wiki/File:Signature_example.png) se cargó **solo en el perfil local «Docente Demo»** para probar la inserción en una vista previa. Es una imagen de ejemplo de dominio público, no corresponde a un docente real y no se incluye en Git.

Antes de publicar un modelo propio para cada tipo, pedir a la oficina responsable:

1. Archivo fuente oficial Word o PDF y una muestra completada sin datos personales reales.
2. Campos que se pueden editar y texto que debe permanecer fijo.
3. Destinatario, revisor y firmante responsables; criterio para la primera hora de tardanza y para prácticas.
4. Documentos adjuntos exigidos, decisiones posibles y condiciones para emitir o rechazar.
5. Numeración y encabezado, pie, sello y ubicación de la firma.

Después, crear una versión de plantilla por tipo, cargar sus campos y comparar el PDF generado con la muestra oficial antes de permitir su uso con expedientes reales.
