# Modelos institucionales pendientes

La **constancia de modalidad de examen de titulación** tiene un ejemplo aportado por el usuario y el PDF final ya incorpora el texto completo del borrador aprobado. Falta verificar la presentación visual contra un archivo fuente oficial.

Para **justificación de tardanza** y **constancia de prácticas**, aún no se han recibido los modelos institucionales. No se debe inventar texto oficial, firmas, destinatarios obligatorios ni criterios de aprobación. El sistema permite registrar el FUT y preparar un borrador. La emisión del PDF oficial de estos dos tipos queda bloqueada para evitar publicar una plantilla genérica como si fuera aprobada por la institución.

Antes de publicar un modelo propio para cada tipo, pedir a la oficina responsable:

1. Archivo fuente oficial Word o PDF y una muestra completada sin datos personales reales.
2. Campos que se pueden editar y texto que debe permanecer fijo.
3. Destinatario, revisor y firmante responsables; criterio para la primera hora de tardanza y para prácticas.
4. Documentos adjuntos exigidos, decisiones posibles y condiciones para emitir o rechazar.
5. Numeración y encabezado, pie, sello y ubicación de la firma.

Después, crear una versión de plantilla por tipo, cargar sus campos y comparar el PDF generado con la muestra oficial antes de permitir su uso con expedientes reales.
